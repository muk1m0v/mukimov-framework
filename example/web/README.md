# Пример сайта на mukimov.web

Из корня исходного проекта выполни:

```bash
python -m pip install -e .
python -m example.web.app
```

Открой [локальный сайт](http://127.0.0.1:8017/). Форма открывается также по пути `/hello`. После отправки имени сервер вернёт 303, и браузер откроет приветствие через GET. При обновлении страницы форма повторно не отправится. Пустая форма показывает страницу 400, а путь `/missing` — страницу 404. На странице `/about/` можно проверить, что CSS, JavaScript и SVG работают и на вложенном адресе.

В `settings.env` пример настроен на порт 8017. В своём приложении можно вызвать `app.run()` для порта 8000 или `app.run(port=8017)` для порта 8017. Сервер слушает `127.0.0.1` и печатает адрес и сочетание клавиш для остановки.

```text
Сервер запущен: http://127.0.0.1:8017
Чтобы остановить сервер, используйте комбинацию: Ctrl + C
Mukimov Web Control - v0.3.8
```

При сохранении Python-файла в папке приложения сервер перезапустится автоматически. Чтобы увидеть результат, обнови страницу в браузере. HTML, CSS и JavaScript перечитываются при новом запросе. Для запуска без перезапуска передай `reload=False`.

Маршруты объявляются через `@app.route(...)`. В примере `@app.view(methods=["GET", "POST"])` разрешает оба метода на `/hello`. По `request.method` обработчик выбирает, показать форму или прочитать поля из `request.form`. Для 400 или 404 можно зарегистрировать свой обработчик через `@app.errorhandler(...)`.

В `templates/home.html` условие `{$ if title $}` показывает приветствие после отправки формы. На странице `/about/` цикл `{$ for asset in assets $}` выводит список файлов. Закрывай условие через `{$ overif $}`, а цикл через `{$ overfor $}`. Значения по-прежнему выводятся через `{{ title }}` и `{{ asset }}`.

`app.py` находится в корне сайта. В `core/conf.py` указаны `DEBUG = True` и `HTML_TEMPLATES = [BASE_DIR / "templates"]`. Этот пример уже содержит свои шаблоны, обработчики 400 и 404 и файлы в `static/`. Команда `python -m mukimov startweb my_site` создаёт чистую заготовку со встроенной стартовой страницей.

Встроенный сервер предназначен для локальной разработки.

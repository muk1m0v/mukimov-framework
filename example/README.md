# Пример mukimov

После установки из любой папки запусти:

```bash
mukimov example
```

Если команда отсутствует в `PATH`, используй `python -m mukimov example`. Из корня исходного проекта также работает `python -m example`.

В терминале Windows или Ubuntu достаточно нажать цифру. В поле пароля используй Enter для завершения ввода и Backspace для проверки стирания маски.

| Клавиша | Пример |
| --- | --- |
| 1 | Ввод тестового пароля со звёздочками |
| 2 | Хеширование пароля `1234ok`, выбор уровня и проверка совпадения |
| 3 | Палитра из 12 цветов |
| 4 | Markdown с таблицей, списком и форматированным текстом |
| 5 | Загрузка типизированных настроек из файла `mukimov/example.env` |
| 6 | Версия, справка и диагностика CLI |
| 0 | Выход |

# Сайт mukimov

Сайт состоит из 12 страниц. Главная помогает выбрать маршрут, а быстрый старт, рецепты, справочник API и страницы модулей открываются по отдельным адресам.

## Локальный запуск

Из корня проекта выполни:

```sh
php -S 127.0.0.1:8000 -t Site
```

Открой [http://127.0.0.1:8000](http://127.0.0.1:8000). Для остановки сервера нажми Ctrl+C.

## Структура

- `index.php` — обзор библиотеки.
- `start.php` и `recipes.php` — установка, первый скрипт и готовые сценарии.
- `web.php`, `hashing.php`, `stars.php`, `colors.php`, `markdown.php`, `env.php` и `cli.php` — страницы отдельных тем.
- `api.php` и `releases.php` — указатель функций и история версий.
- `_layout.php` — общий шаблон и навигация.
- `style.css` и `app.js` — две чёрно-белые темы, фильтр API и копирование примеров. Кнопка смены темы находится в шапке.

## Публикация

Загрузи содержимое `Site` в папку, которую обслуживает PHP на твоём хостинге. Главная страница — `index.php`. Ссылки относительные, поэтому сайт можно разместить и в подпапке. Достаточно PHP 7.3 или новее. База данных, сборка и правила перенаправления не нужны.
